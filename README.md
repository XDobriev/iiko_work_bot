# 🧾 iiko Work Bot (v2.0 TypeScript)

Telegram-бот для автоматического распознавания рукописных накладных ресторана с помощью **Google Gemini 3.8 Flash Vision**, локальной базы данных **SQLite** с исторической памятью цен и интеграцией в **iiko Cloud API**.

---

## 🌟 Ключевые возможности

1. **Распознавание рукописного текста (Gemini 3.8 Flash Vision):**
   - Точное извлечение наименований позиций, количества, цен, сумм и рукописного итога.
   - Автоматическое определение склада: **Склад Кухня** (продукты) или **Хоз склад** (бытовая химия, перчатки, салфетки, расходники).

2. **Обучение на опыте и историческая память (SQLite):**
   - Бот помнит все ранее подтвержденные товары и поставщиков.
   - Перед каждым распознаванием бот передает список известных ресторану товаров в контекст Gemini, чтобы модель точнее понимала почерк и терминологию заведения.

3. **Сверка цен и аналитика (Price Intelligence):**
   - Сравнивает цену каждого товара с предыдущими закупками.
   - Предупреждает о подорожании: `🔺 Говядина: 600 ₽ (+50 ₽ / +9.1% к 15.10.2026)`.
   - Показывает скидки и новые позиции.

4. **Защита от ошибок и дубликатов:**
   - **Контроль дубликатов:** предупреждает, если накладная от этого поставщика за эту дату уже загружалась ранее.
   - **Сверка математики:** проверяет соответствие написанного от руки итога с суммой позиций (`qty * price`).

5. **Параллельная обработка (до 10 фото в день):**
   - Каждое фото получает свой `ID` в базе данных и отдельную карточку с инлайн-кнопками. Никаких конфликтов состояний (в отличие от старого бота).

6. **Интеграция с iiko Cloud API:**
   - По нажатию кнопки `[✅ Создать в iiko]` автоматически создает приходную накладную.
   - Если пароль iiko не указан в `.env`, бот работает в **безопасном демо-режиме** без ошибок.

## 🚀 Быстрый старт

### 1. Установка зависимостей (уже выполнена)
```bash
npm install
```

### 2. Настройка окружения (`.env`)
Файл `.env` уже содержит настроенный и проверенный ключ Gemini:
```env
# Gemini API
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.8-flash

# Telegram Bot Token (от @BotFather)
TELEGRAM_TOKEN=your_telegram_bot_token_here

# iiko API (по желанию)
IIKO_URL=https://beyni.iikoweb.ru
IIKO_LOGIN=dobriev
IIKO_PASSWORD=
```

### 3. Запуск бота
```bash
# Режим разработки с автоперезагрузкой:
npm run dev

# Либо обычный запуск:
npm start
```

### 4. Тестирование всего конвейера без Telegram
```bash
npm run test:pipeline
```
